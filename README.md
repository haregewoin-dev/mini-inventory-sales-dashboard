# mini-inventory-sales-dashboard

A modern, full‑stack inventory and sales management system built to show clean architecture, secure authentication, role‑based access control, optimized database queries, and a professional CI/CD workflow. Built with scalability in mind, this project provides a solid foundation for real‑world business operations such as product tracking, stock management, sales recording, and analytics.
🚀 Features
**1. Inventory Management**
Add, edit, delete, and view products
Track stock levels in real time
Low‑stock alerts
SKU‑based product identification

**2. Sales Tracking**
Record sales transactions
Auto‑update inventory quantities
View sales history with filters
Track revenue and best‑selling items

**3. Dashboard & Analytics**
Total sales summary
Inventory value
Best‑selling products
Recent activity feed

**4. Activity Logging**
Logs product changes, stock movements, and sales
JSON metadata for flexible auditing
User‑linked actions for accountability

**Frontend**

**Backend**
Node.js

**Database**
